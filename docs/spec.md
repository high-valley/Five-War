## 1. コンセプト

- ドット絵のファンタジー世界で、1人の主人公を日数制で育てる**育成ローグライク**。
- 戦闘は**5手を並べて連続でぶつける読み合い**。敵の手は見えず、敵ごとの「癖（確率）」に賭けて札を選ぶ。
- 運と実力の両方が効く：手札の配られ方と必殺は運、癖の読みと札の構成は実力。
- 旅に失敗しても「魂片」で永続強化を解放し、周回ごとに強いキャラを作りやすくなる。

参考にした遊びの型：パワプロのサクセス（日数制育成）、ファイアーエムブレム（戦闘カットイン、クラスチェンジ）、格闘ゲーム（連続技の爽快感）。キャラ・名前・絵はすべて独自。

## 2. 戦闘

### 2.1 流れ

1. 1戦（ラウンド）ごとに、自分の札の束から**7枚**が配られる。
2. 7枚から**5枚**を選んで順番に並べる。5手目は**奥義枠**（ダメージ1.5倍）。
3. 敵も5手を決める（敵の手は見えない）。
4. 1手目から5手目まで同時にぶつかり、演出つきで連続再生する。
5. どちらかのHPが0になるか、**最大8戦**で決着。8戦で決着しない場合はHP残量の割合が多い方の勝ち。

### 2.2 行動（4種）

| 札 | 名前 | 役割 |
|---|---|---|
| 弱 | 弱攻撃 | 速い。強攻撃の出がかりを潰す |
| 強 | 強攻撃 | 重い。防御を崩す |
| 返 | カウンター | 攻撃を受け流して反撃。防御には空振り |
| 防 | 防御 | 弱攻撃を無傷で受ける。カウンターを空振りさせる |

### 2.3 相性表（自分の行動 × 敵の行動）

| 自分＼敵 | 弱 | 強 | 返 | 防 |
|---|---|---|---|---|
| 弱 | 相打ち（両者 弱ダメージ） | 潰す（弱×1.5） | 反撃される | 防がれる |
| 強 | 潰される | 激突（両者 強×0.6） | 大反撃される | 崩す（強×0.7） |
| 返 | 小反撃（相手の弱と同等） | 大反撃 | 何も起きない | 空振りで**隙** |
| 防 | 無傷 | 崩される | 相手に**隙** | 何も起きない |

- **隙**：次の手で受けるダメージ1.5倍。
- 怯み中（後述）の相手に対しては、弱・強はそのまま通る。

### 2.4 ダメージ計算

基礎値（攻撃側 a、防御側 d）：

```
弱 bW = max(1, 2 + a.技×0.7 + a.力×0.3 − d.守×0.4)
強 bH = max(2, 5 + a.力×1.5 − d.守×0.5)
大反撃 = 相手の bH×0.7 + 自分の技×0.8
```

最終ダメージ：

```
0.6 × (基礎値 + 連携ボーナス)
  × 連勝倍率 [1, 1, 1.25, 1.5, 1.75, 2]
  × 奥義枠 1.5（5手目のみ）
  × 隙 1.5
  × 必殺 1.75（確率 = min(45%, 3% + 運×1.5%)）
  × 各種補正（秘伝・銘・仲間）
```

- **連勝**：一方だけがダメージを与えた手が続くと倍率が上がる。両者ダメージ／両者0でリセット。
- **連携**（並びで成立、最後の札が一方的に当たった時のみ加算）

| 並び | 名前 | ボーナス |
|---|---|---|
| 弱弱強 | 三段打ち | +8 |
| 返強 | 返し斬り | +6 |
| 防強 | 溜め崩し | +5 |
| 弱強 | 繋ぎ | +3 |
| 弱弱 | 連打 | +2 |

### 2.5 強靭と怯み

- 受けたダメージが「怯み値」としてたまる（強攻撃は1.5倍、銘「鉄砕」でさらに1.4倍）。
- 怯み値が**強靭**に達すると怯み（BREAK）。**次の1手が不発**になり、一方的に攻撃される。
- 怯み値はラウンドごとにリセット。

### 2.6 敵の癖（確率の公開）

- 敵ごとに行動の重み `w` を持つ（例：ゴブリン 弱5・強2・返0.5・防1.5）。
- 手番ごとの偏り `bias`（例：`WWHWH` → その手番は該当行動の重み×2.5）。
- 画面には5手全体の平均確率（例：弱62%、強24%…）だけを表示する。
- ボスは HP 50%以下で重みが `w2` に切り替わる（「構えが変わった」と表示）。
- **学習**：関門ボスは、プレイヤーが多用した行動への対策を毎ラウンド少しずつ増やす（弱/強→返、返→防、防→強）。
- ツリー「観察眼」で手番ごとの最有力予想、「看破」・秘伝「見切り」で毎回1手を確定表示。

### 2.7 演出

- 一手ごとに一騎打ちの横視点カットイン。剣は斬撃、槍は突進、斧は跳びかかり。
- 奥義は暗転＋技名カットイン＋光柱・雷・炎のエフェクト。
- ヒットストップ、画面揺れ、数字ポップ、BREAK表示。早送りあり。

### 2.8 バランス確認（シミュレーション、各400戦）

| 関門 | 手番ごとに読む | 癖だけ読む | 適当 |
|---|---|---|---|
| 関門1 | 63% | 54% | 17% |
| 関門2 | 33% | 24% | 3% |
| 関門3 | 84% | 79% | 50% |

「運で負けることもあるが、読むほど勝てる」範囲。関門2（骸骨王）は手が散らばるため厳しめで要調整。

## 3. 育成（1回の旅）

### 3.1 基本

- 旅は **24日**（ツリーで+4）。8日ごとに**関門ボス**（3体）。負けたら旅は終了。
- 最初の関門突破で**クラスチェンジ**（2択）。
- 体力（0〜100）、所持金、鉱石を管理する。体力30未満だと戦闘開始時HPが2割減。

### 3.2 1日の行動（1つ選ぶ）

| 行動 | 効果 |
|---|---|
| 鍛える | 体力−20。力・技・守 +3、HP +8、運 +2、強靭 +6（ツリーで+1〜2） |
| 町の外へ | 体力−15。3体から選んで戦闘。勝つと金・鉱石・能力 |
| 買い物 | 装備、札の追加/削除、秘伝書（1日使う） |
| 鍛冶屋 | 鉱石と金で武器を錬成 |
| 酒場 | 仲間を雇う（最大2人、1日使う） |
| 休む | 体力+50 |

- 約28%の確率で**出来事**（2択イベント）が起きる。

## 5. 周回要素（メタ進行）

- 旅の終わりに**魂片**を獲得：日数 + 勝利数×3 + 関門×15 + 踏破40。
- 地方を踏破すると次の地方が開く。
- **殿堂**：旅の結果を能力値とランク（S〜E）で上位10件まで記録。

### 継承ツリー

| 系統 | ノード（必要魂片） |
|---|---|
| 鍛錬 | 基礎体力 HP+10（10）→ 星の巡り 運+3（20）／鍛錬の心得 上昇+1（30）→ 名コーチ 体力消費−5（60）→ 長い旅路 +4日（80） |
| 見識 | 観察眼 手番予想（15）→ 看破 1手確定（45）／商才 +100G（15）→ 行商人 買い物で日が進まない（50）／鉱山の縁 鉱石+3（20） |
| 秘伝 | 秘伝の巻・上（20）→ 秘伝の巻・下（50）→ 継承 殿堂1位の能力15%を引き継ぐ（90） |

## 7. 未実装・今後の案

1. **途中の差し替え**：5手の途中で1回、次の札を入れ替えられる（逆転要素）。最優先候補。
2. **挑発札**：次の手の敵の傾向をずらす。
3. **天候・地形**：「雨で強攻撃が弱まる」など戦場ごとの条件。
4. **殿堂キャラの非同期対戦**：育てたキャラのデータだけをサーバーに上げて他人と戦わせる。低コスト・低リスクなオンライン化。
5. 関門2の難易度調整、1戦の長さの調整（現在 平均2〜3ラウンド）。
